To update your location filter so it reflects only the actual hospital locations in your doctors dataset — and remove the outdated hardcoded options — you can dynamically populate the <select id="location-filter"> dropdown with values from the doctors array.

Here’s how you can do it:

✅ Step 1: Remove hardcoded location options from HTML

In your HTML, replace this section:

html
<select id="location-filter" class="btn light">
    <option value="">All Locations</option>
    <option value="Princeton-Plainsboro Teaching Hospital">Princeton-Plainsboro</option>
    <option value="Cebu Doctors' University Hospital">Cebu</option>
    <option value="Adventist Medical Center Manila">Manila</option>
</select>

with just the base element:

html
<select id="location-filter" class="btn light">
    <option value="">All Locations</option>
</select>

✅ Step 2: Add JavaScript to populate location options dynamically

Place this function before your initial rendering logic, and call it after const locationFilter = document.getElementById("location-filter");.

js
function populateLocationFilter() {
    const uniqueLocations = [...new Set(doctors.map(doc => doc.location))].sort();

    // Clear any existing options except "All Locations"
    locationFilter.innerHTML = '<option value="">All Locations</option>';

    uniqueLocations.forEach(location => {
        const option = document.createElement("option");
        option.value = location;
        option.textContent = location;
        locationFilter.appendChild(option);
    });
}

Then call the function:

js
populateLocationFilter();

✅ Final Integration

Ensure your JS section includes these function calls:

js
populateLocationFilter();
populateSpecialtyFilter();
applyAvailabilityFilter();
renderDoctors(filteredDoctors);

✅ Result

  • The location filter dropdown will now only contain locations present in your actual doctor dataset.

  • It will automatically update if doctors or locations change in the data.
